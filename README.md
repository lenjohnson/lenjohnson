I build web products, and I teach students to build theirs so that someone else can inspect their work and assess their capability: documented, version-controlled, with AI use recorded rather than hidden.

## What's here

**[prismmo-starter-pack](https://github.com/lenjohnson/prismmo-starter-pack)**
Git workflow conventions and a structured log that make AI-assisted development visible and assessable. For educators who need to see which decisions were the student's.

**[milestone-project-starter](https://github.com/lenjohnson/milestone-project-starter)**
The template my Level 5 WAD students start from: a README scaffold, an AI-use log, and a checklist mapped to the assessment criteria. For students who want their project to read like a professional repo from the first commit.

## How I work

Documentation is part of the build. If the README can't explain it, it isn't finished.

AI use gets logged, not hidden. The log is evidence of judgement, not an admission.

Student projects are structured like agency repos, so a first job isn't the first time they've seen one.
